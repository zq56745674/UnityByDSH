## 1. 项目全景

### 1.1 架构

```
Bootstrap（场景里唯一的物体）
 └─ GameController   状态机：Fighting / WaitingRespawn / Shopping / SkillChoice / Reviving
     ├─ BattleSystem   伤害、暴击、技能触发、冷却、Buff
     ├─ LootSystem     掉落与词条随机
     ├─ EquipmentScore 装备评分（期望 DPS + 有效生命/8）
     ├─ StageCatalog   11 章 × 10 关，纯规则生成
     ├─ PlayerData     等级 / 巅峰 / 装备 / 技能槽 / 关卡进度
     ├─ SaveSystem     PlayerPrefs，3 个存档槽，v6 带迁移
     └─ GameUI         全部 UGUI 由代码搭（4 个 partial），无 prefab
```

### 1.2 核心循环

挂机打怪 → 掉落装备（30%）→ 自动换装（评分更高才换）→ 击杀给经验 → 升级/巅峰 → 推关。
每关击杀 3~6 只，最后一只必为精英，章末关底为 Boss。首通给金币。

### 1.3 关键公式（当前值）

| 项 | 公式 | 备注 |
|---|---|---|
| 升级经验 | `30 + 15L + 2L²` | Lv.1 需 47，Lv.99 需 21,117；1→100 共 733,920 |
| 怪物经验 | `(10+5L) × 类型(1/1.15/1.35) × 档次(1/2/5) × (1+0.07(L−1))` | Lv.110 Boss ≈ 24k~32k |
| 巅峰经验 | `2000 + 200p + 20p²`，上限 P1000 | P0→200 累计 5,731 万；P0→1000 累计约 67.5 亿（2026-10-21 实测 6,752,530,000） |
| 巅峰属性 | 每级 +1 攻 / +1 防 / +50 HP，每 10 级 +1 技能 | 技能共 15 张，槽位只有 6 个 |
| 伤害 | `攻击 × (1 − 防/(防+100+20×等级)) × 0.9~1.1`，暴击再乘倍率 | 百分比减伤，永不免疫 |
| 出手间隔 | `2 / (1 + 速度/20)`，下限 0.2s | 速度对间隔非线性 |
| 关卡怪级 | 第 c 章 `Lv.10(c−1)+1 … 10c` | 1-1 是 Lv.1，11-10 是 Lv.110 |
| Lv.110 额外倍率 | 生命/攻击/防御 ×3，速度 ×2（叠加精英 ×1.5 / Boss ×2.5） | `MaxTier*Factor` |

### 1.4 内容量

110 关、首通 480 只怪、15 张技能卡、5 种装备品质、7 种怪物词缀（Boss 不带词缀）、
3 个存档槽、首通金币合计 63,800。

近战血最厚，早期输出不够时会被拖死；暴击居中。10 次首通里 9 次落在远程/暴击轮换位，
唯一一次近战首通在第 49 次（P53）——这比「固定第几次过关」更能解释玩家体感。

## 4. 100 级之后到底在玩什么

### 4.1 经济

- 单只 Lv.110 怪经验：普通 4.8k~6.5k，精英 9.7k~13k，Boss 24k~32k。
- 单级巅峰需求（二次曲线）：P0 2,000 → P100 222,000 → P199 833,800。
  **P0 时 1 只 Boss 约 10 级，P100 时只够 1/7 级**——巅峰曲线越往后越依赖重复刷。
- 全程 P0→P200 累计约 5,731 万经验。按第 11 章「5 小怪 + BOSS」循环（2026-10-21 五槽实测），
  纯战斗约 **62 分钟**；含每只 0.5s 刷怪与每次 BOSS 前 3s 商店约 **165 分钟**（x4 档约 41 分钟）；只打到 P150 纯战斗 30 分钟、含等待 75 分钟。两槽旧口径是 114 / 225 分钟。
- P0→P1000 累计约 67.5 亿经验（1,000 级），同一循环实测含等待 **18,066 分钟 = 301.1 小时 = 12.5 天**（x4 档约 75 小时）；从 P200 起算约 12.4 天（17,901 分钟）。

### 4.2 阵亡返经验把墙变成楼梯

`HandlePlayerDied` 按已打掉的血量占比给经验，且不扣金币、不掉进度（只清本关击杀数）。
11-10 第一次尝试通常只能打掉个位数到一成的血（Lv.100/P48 无技能实测：近战约 9%、暴击约 8%、远程约 6%），每死一次拿到的经验很薄。
新档探针就是这么过去的：不洗练口径 **88 次尝试、87 次阵亡，把巅峰刷到 60，然后打通**；默认洗练 80% 口径只要 **11 次尝试、10 次阵亡、P44**（2026-10-19 复测；旧口径是 27/26/P102）。注：以上是两槽口径；2026-10-21 五槽复测 6 个种子的第 11 章中位尝试是「开洗练 22 / 关洗练 21.5」，差距落在噪声内，见 §3.5.1 末尾。

所以终局的原型不是"变强了再挑战"，而是"反复送死，直到数值够"。
到 P60 技能槽满之后，玩家几乎没有决策：装备已是最好的、技能不能再换，只能等。

### 4.3 Lv.110 Boss 为什么是墙

按公式实算 Lv.110 远程 Boss：

- 攻击 ≈ 339 × 1.45（类型）× 2.5（档次）× 3（最高档）× 1.6（终局）= **5,846**（实测）
- 速度 ≈ 43 × 1.45 × 1.5 × 2 = **187** → 出手间隔被压到下限 **0.2 秒（5 次/秒）**
- 对 Lv.100、防御 677 的主角：减伤 24% → **单次 ~4,420，DPS ~22,100**
- 主角 P0 满级传说约 8,882 血 → **0.4 秒阵亡**

而主角在 0.4 秒内只能打出约 840~1,494 伤害，连 Boss 的 1/10 血都不到——数值上必输。
唯一翻盘手段是技能（免死、护盾、吸血、斩杀）与巅峰血量。
**这正是「巅峰 60 级后胜率靠技能而不是数值」的根源**。

## 5. 结构性判断

| # | 结论 | 证据 |
|---|---|---|
| 1 | **难度曲线是「1~10 章缓降 + 11-10 一堵墙」** | 关底胜率从第 1 章 98% 降到第 10 章 28%；新档前 109 关零阵亡，11-10 才出现阵亡（不洗练 87 次；默认洗练 10 次） |

## 6. 建议（按性价比排序）

1. **削平终局单点**：`MaxTierAttackFactor` 3 → 2.2、`MaxTierSpeedFactor` 2 → 1.5。
   让 Lv.110 Boss 的出手从 5 次/秒回到 3.5 次/秒，P0 的胜率从约 0% 抬到 10~15%，
   同时保留「需要巅峰」的性质。
2. **巅峰经验改成超线性**：`ParagonExpToNext = 2000 + 200p + q·p²`。这里原本建议 `q=6`，实际落地先用 12、再用 20（见 8.3 的二次校准）。
   P0→200 累计从 438 万涨到约 5,731 万，终局纯战斗从约 40 分钟拉到约 114 分钟（含刷怪+商店 225 分钟），
   让 P150 之后还有目标。
3. **阵亡返经验打个折**（例如 60%），并且对 Boss 只按 50% 折算；
   现在"送死"是收益最高的打法，这条会直接鼓励正确玩法。
4. **技能槽随巅峰扩展**：P60/P100/P150 各 +1 槽（6 → 9），
   否则第 7~15 张技能卡没有意义。
5. **终局 Boss 固定类型**（或按章节轮换），去掉 11-10 的掷骰；
   类型差异建议控制在 ±15% 以内。
6. **给 1~9 章加一点压力**：例如章末 Boss 也吃 `MaxTier*` 的一个较低档位（×1.3），
   或者把"越级挑战"做成可选高难，让挂机过程不是纯读条。

## 9. 装备洗练的经济账（2026-10-18）

洗练（`docs/equipment-reforge.md`）是第一个真正意义上的金币出口：重抽全部副词条、条数不变、主属性与强化等级不动，
费用 `(200 + 14×(Lv−1)) × 品质系数 × (1 + 0.6×已洗次数)`。

| 项 | 数值 |
|---|---|
| Lv.100 传说首次洗练 | 2,538 金币 |
| 第 2 / 3 次 | 4,060 / 5,583（每次 ×1.6 递增） |
| 一件洗到 20 次累计 | ≈ 34 万金币 |
| P200 满级时兜里 | ≈ 560 万金币（2026-10-21 五槽 P1000 实收 8.598 亿） |
| 锁 0 / 1 / 2 / 3 条的单价倍率 | ×1 / ×3 / ×9 / ×27 |
| 锁 1 条洗一次（同装备第 4 次，实测） | 21,316 金币 |
| 锁 3 条洗一次（同装备第 5 次，实测） | 274,061 金币 |
| 锁 3 条追 80% 词条质量的中位累计 | ≈ 7 万金币（锁 0 条约 135 万；蒙特卡洛 10 万次，见设计文档 §10.6） |

两条设计约束决定了它只能当「软出口」：

1. **天花板不变**：抽样与掉落共用同一段 `RollAffixes(level, count)`，所以洗练的最好结果就是掉落的最好结果。它买的是确定性，不是强度上限——终局 BOSS 的 ×1.6 标定因此不用重调。
2. **边际收益递减**：词条集合固定、条数固定，洗 N 次后的期望质量收敛得很快；玩家会在「够了」的时候停手，那之后金币重新变成死钱。

同日上线的**锁词条**把「软出口」往前推了一格，但没动天花板：锁定只是把待抽条数从 4 压到 4−k，分布本身一字未改。锁 k 条后追到 80% 词条质量的中位次数 58 → 17 → 5.6 → 2.0，所以哪怕单价按 `3^k` 指数加价（锁 3 条一次 27 万），累计花费反而从约 135 万降到约 7 万——玩家买的是**确定性**，不是更强。这也正是「锁定」与「保底」的分界：保底改分布（会抬天花板，得重估终局 BOSS），锁定只改抽样自由度（天花板不变）。

如果以后要让金币继续有意义，方向是另开出口（成就 / 转生 / 提高强化上限），而不是再加锁定档位——锁定给的确定性是一次性的，锁完之后金币照样会堆起来。
洗练**已进探针**（2026-10-19）：`ProbePolicy.SpendGoldOnReforge` 会在每次 BOSS 前把词条质量洗到 80%，锁住已达标的词条，不追 90%；`NewGameProgression` / `EndgamePacing` / `EndlessPacing` 都已接入。新档 A/B（两槽）显示洗练把 11-10 从 88 次尝试 / 87 阵亡降到 11 次 / 10 阵亡，只花 2,674 金——收益偏大，作为待定平衡风险记录。2026-10-21 五槽复测未复现该差距（6 种子中位 22 / 21.5），洗练单价也已接近新档整轮收入，故该风险条目改为「五槽下不成立」（见 docs/equipment-reforge.md §5.4–5.6）。

## 10. 无尽模式基线（2026-10-19）

无尽模式（`docs/endless-mode.md`）用独立探针 `EndlessPacing` 标定：满装模板（Lv.100 巅峰 200、15 技能、传说 Lv.110 +15、词条质量 80%），20 个固定种子，最多 100 层，自动喝药/强化/换装。模板词条已在 80%，所以洗练不会额外动作；这里的数字仍是「P200 满装」口径。

| 配置（EndlessBaseFactor / Step） | 首死中位 | 备注 |
|---|---:|---|
| 2.5 / 2（首版默认） | 无 | 20 局全部打满 100 层 |
| 6 / 2 | 无 | 高防模板也打满 |
| 8 / 2 | 15 | 过难 |
| 6.25 / 2 | 30 | 偏难 |
| 3 / 6 | 45 | 中位达标，但 0 局到 50 层 |
| **2.8 / 6（采用）** | **45** | 20 局全部阵亡，2 局到 50 层 |

最终基线：首死 min 30 / P10 30 / 中位 45 / P90 50 / max 60；单层耗时 P90 最大约 16.1 秒；50 层累计金币平均 371,940、经验 2,602,923（仅 2 局达到）。

判断：中位落在设计目标 35~50 层；50 层金币约为终局量级（P200 约 560 万）的 6%，无尽不是刷钱捷径。探针默认会把词条洗到 80%，但这个模板本身已经是 80%，所以洗练不影响这组数字；真人从低质量装备起步时首死层数会更高。若后续改无尽系数，按 `docs/endless-mode.md` §12.2 的顺序调参并重跑探针。

### 10.1 P1000 装备上限口径（2026-10-19，当前）

巅峰上限提到 1000 后，用 P1000 + 传说 Lv150、品质倍率 4.80、+15、词条全满的模板（攻 4,091 / 防 2,880 / 血 65,361 / 暴击 95% / 暴伤 276%），50 个固定种子、最多 300 层：首死 min 167 / P10 196 / 中位 221 / P90 235 / max 250，50 局全部阵亡、0 局打满 300；最高纪录 250 层。层通过率 200 层 44/44、215 层 32/36（89%）、220 层 26/28（93%）、225 层 17/21（81%）、230 层 8/14（57%）、235 层 4/6（67%）、250 层 0/1。单层 P90 最大 24.5 秒（230 层）；50 层累计金币平均 4,764,593、经验 10,675,549。结论：P1000 满配天花板约 220~235 层，最高 250 层，近战 BOSS 仍是后期墙。详见 `docs/endless-mode.md` §12.5.1。

### 10.2 P200 装备上限对照（历史）

按旧巅峰上限把装备也拉到顶（P200、传说 Lv150、品质倍率 4.80、+15、词条全满）后，200 个种子：首死 min 45 / P10 45 / 中位 60 / P90 60 / max 75，最高清到第 74 层；50 层累计金币平均 411,234、经验 2,791,774（166 局到达）。瓶颈是第 60/75 层近战 BOSS（HP 104,328 / DEF 12,490；HP 124,488 / DEF 14,909），而第 65 层远程、第 70 层暴击 BOSS 反而 100% 通过。这与上面的满装模板（Lv110 / 80% 词条、中位 45）是两个口径，不要混用；详见 `docs/endless-mode.md` §12.5。
