# Unity AutoBattle 传说主暴伤压低 + 词条收益/阈值复评

工程 `HelloWorldProject/`（Unity 2D，Editor 6000.6.5f1）。承接装备评分换口径（线性权重 → 增量期望 DPS）之后的收尾动作：压低武器主暴伤、修技能栏 UI、并以新评分口径复评「属性收益 / 阈值 / 评分是否合适」。

**相关既有文档**
- `4f6621d0-f8c4-4dab-81fb-719d78ddf259`：评分口径改造本身（增量期望 DPS + 有效生命/8、木桩 Spearman ρ 0.090→0.914、`Equipment.Score`→`LegacyScore`）与本文改动前的失衡初判（暴击率词条价值是暴伤 7.5 倍、传说衣被稀有衣顶掉）。本文是该文之后**修复 + 复评**的续篇，两者数字不可混用（角色总暴伤口径已变）。
- `e0af2b00-883b-47fe-ad14-f22f8f78f565`：攻速上限/攻速上限漏洞/护甲穿透与减伤公式/词条池 4→5/怪物速度表。本文的阈值实测全部依赖该文的 `MinAttackInterval = 0.2s`、穿透 80% 上限与穿透伤害公式。
- `a68e8f3d-4799-4bff-8ae2-942a12bae043`、`7c3b8ebf-3e86-4b45-8f70-ad53ec9188c5`（技能与巅峰）：技能数值仍有效，但本文改了武器主暴伤与（尚未落地的）词条范围建议。

## 1. 武器主暴伤压到 150%

- `HelloWorldProject/Assets/Scripts/GameConfig.cs`：`WeaponCritDamagePerLevel` 由 `0.01f` 改为 **`0.00195f`**；`WeaponBaseCritDamage` 仍为 `0.10`。
- 动机：改前角色总暴伤 **643%**，与暴击率（15% 量级）差约 40 倍，暴击率词条被暴伤词条的乘数放大到失衡。
- 实测 400 把/档（传说武器）：

| 等级 | 主暴伤范围 | 主暴击率范围 |
|---|---|---|
| Lv.50 | 78.2%~93.8% | 23.6%~28.3% |
| Lv.100 | 117.6%~140.3% | 47.6%~57.1% |
| **Lv.110** | **125.1%~150.0%** | 52.4%~57.1% |

- 效果：角色总暴伤 **643% → 331%**，两个乘数的量级不再相差 40 倍。

## 2. 技能槽名称与「就绪」重叠（UI）

- 根因：槽位只有 50px 高，名称标签 `offsetMin.y = 19` 与冷却文本基线 24 挤在一起。
- 修法（`HelloWorldProject/Assets/Scripts/GameUI.cs`）：槽位高 **50 → 58px**，名称标签范围收到 `offsetMin.y = 38 / offsetMax.y = -16`。
- 证据截图：`HelloWorldProject/Assets/Screenshots/ui-skill-fix.png`（修复后「狂暴之心」与「就绪」之间有明显间隔）。

## 3. 新口径下的属性收益 / 阈值复评

**基准**：Lv.100 传说套（攻击 1232 / 面板暴击 64.6% / 暴伤 150.0% / 攻速 0% / 穿透 0%，间隔 0.310s，DPS 2203），对手 Lv.110 Boss（防御 3187）。

### 3.1 每 +1 单位属性的 DPS 提升

| 属性 | +1 单位 → DPS |
|---|---|
| 攻击 +1 | +0.0812% |
| 暴击率 +1% | +0.3779% |
| 暴击伤害 +1% | +0.4883% |
| 攻击速度 +1% | **+1.0000%** |
| 全属性 +1% | +0.9740% |
| 护甲穿透 +1% | +0.5842% |

换成**一条词条的典型值**（Lv.100 传说，等级缩放 ×1.5）：

| 词条 | 单条范围 | 均值 | 折算 DPS |
|---|---|---|---|
| 暴击伤害 | 7.5%~60% | 33.8% | **+16.5%** |
| 攻击速度 | 3%~15% | 9% | **+9.0%** |
| 全属性 | 3%~12% | 7.5% | **+7.3%** |
| 护甲穿透 | 3%~15% | 9% | **+5.3%** |
| 暴击率 | 1.5%~12% | 6.8% | **+2.6%** |

### 3.2 阈值与拐点（实测扫描）

| 属性 | 拐点 |
|---|---|
| **攻击速度** | **+60% 撞顶**（间隔夹到 0.2s）。`+60% → +200%` 收益 **+0.0%**。扫描：+25%→0.248s、+50%→0.207s、+60%→0.200s，之后恒定 |
| **暴击率** | **95% 硬顶**（`GameConfig.MaxCritChance`），词条只需 +35% 就满。+35%/~+40%/~+50% 面板都 95.0%，DPS 恒为 2407 |
| **暴击伤害** | 无硬顶，**边际递减**：175% → +12.2% / 300% → +7.6% / 450% → +5.2% |
| **护甲穿透** | 无硬顶（合计夹 80%），**边际递增**：10% → +6.2% / 50% → +8.2% / 80% → **+10.8%**（扫描 10%→DPS 2340、40%→2870、80%→4116） |
| 全属性 | 线性，无拐点 |

### 3.3 评分口径自动吃到阈值（结论：评分合适，无需打补丁）

评分 = 「相对同槽位空槽的 Δ期望 DPS + Δ有效生命 ÷ 8」，攻速/暴击上限因此天然生效：

| 角色已有攻速 | 面板间隔 | 同一把「攻击 900 + 攻速 15%」武器的评分 |
|---|---|---|
| +0% | 0.310s | 3135 |
| +30% | 0.239s | 3918 |
| +45% | 0.214s | 4136 |
| **+60%（顶）** | 0.200s | **4047** |
| +120%（顶） | 0.200s | 4047 |

撞顶后同一把武器评分**不再上涨反而回落**，因为空槽基线也封顶了——这正是旧线性权重做不到的。同槽位比较不受 `/8` 影响（武器不改有效生命、衣服不改 DPS）。另有一致性验证：同一把「攻击 900 + 攻速 15%」武器的评分不随玩家已有攻速变化（3135 恒定，仅在替换口径下随空间占用而变）；「攻击 900 + 暴击率 10%」武器的评分随衣服暴击率升高而升高（2774 → 2958 → 3081 → 3142 → 3326）。

## 4. 复评暴露的三个平衡问题（评级可信，问题真实）

1. **攻速溢出太容易发生**：词条 + 迅捷技能（+12%/级）+ 狂暴（+50%）很容易越过 +60%，溢出部分**完全无效**；且高攻速装备会因撞顶显示低分，玩家会困惑。
2. **护甲穿透是唯一反递减属性**：越堆越强（+6.2% → +10.8%），配 80% 上限后几乎成为必堆项。
3. **平衡从「暴击率碾压暴伤」反转为「暴伤碾压暴击率」**：新上限下暴伤词条（+16.5% DPS）是暴击率词条（+2.6%）的 **6.3 倍**（改前是暴击率强 7.5 倍，方向相反）。词条池两者等概率出现（池 5 种），所以传说暴击率装备现在会被优秀暴伤装备顶掉。

**未决（用户尚未回答）**：建议方向是**调词条范围**（暴伤 60% 偏高、暴击率 12% 偏低）；已向用户提出二选一——按此方向调，还是先看实战胜率偏移多少再定。
