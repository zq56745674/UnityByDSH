## B9 → 技能 2.0 双流派（设计稿，未实现）

设计稿：`docs/skill-system-v2-design.md`（664 行 / 24,038 字符，16 章）。旧稿 `docs/skill-build-design.md` 顶部已加「内容层见新稿」交叉链接，并把「存档 v15（原计划 v14，已被 B1 占用）」写进正文。

### 架构

- 15 技能 = 6 风暴专属 + 6 山崩专属 + 3 通用；仍是 2 主动 / 2 被动 / 2 触发（`SkillSlotsPerKind=2`）。
- P10 选流派（README 写「P10 二选一」），流派核心不占槽、本世锁定、转生可重选；P20~P70 六次三选一集齐 6 个专属；P80~P100 三次通用（可替换或留池）。
- 另一流派 6 格灰显不可装；技能在营地/暂停自由替换；满槽时新技能入池 + banner 提示，不自动挤掉已装技能。
- 技能池只显示「本流派 6 + 通用 3」；通用技能占同类空槽，不能跨类别。
- 否决的备选：8 槽（UI 与左栏要重排，毕业 build 只是更长不是更多选择）、四选一（不解决卡池无连携）、技能等级/符文（与 `SkillLevelScale=0` 冲突，变成刷等级）、装备套装（与五槽词条乘区叠加失控）。

### 两套流派核心

- 风暴之眼（雷印 0~8，每层 +1.5% 攻速）：普攻 +1；暴击额外 +1（1s ICD）；雷霆突袭 +2；雷殛 +1。满 8 层后下一次普攻变连锁闪电：180% 攻击力主伤害 + 90% 跳到同目标或最多 2 个额外目标；每命中目标施加 1 层感电（最多 3 层，每层 +6% 受伤，6s，刷新不叠层）并回复 1.5% 最大生命；连锁闪电不产雷印，释放后清零。
- 山崩之心（岩层 0~3，每层 +2% 减伤）：受击 +1（1.5s ICD）；每第 2 次普攻 +1。满 3 层后下一次普攻变崩山：330% 攻击力 + 破甲（防御 ×0.75，5s）+ 压制（速度 -20%，1.5s）；崩山算普攻，可暴击、吸血、触发普攻类效果。
- 毕业组合：风暴 = 雷霆突袭 / 雷神降临 / 静电共鸣 / 风暴加速 / 电弧 / 雷殛；山崩 = 崩山击 / 磐石壁垒 / 山岳之躯 / 沉重打击 / 余震 / 岩甲。通用 3 个 = 战吼 / 吸血鬼 / 保命。

### 强度与手感（纸面预算）

- 风暴：DPS 指数 125（≈59.4k）/ EHP 指数 80（≈236k）/ 几何综合 100。
- 山崩：DPS 指数 107（≈50.8k）/ EHP 指数 100（≈295k）/ 几何综合 103.4。
- 两套综合差 3.4%，在「强度相当」的 5% 容差内；文档明确标注纸面预算必须探针实测校准，两套 build 各 50 种子都要落在无尽 235~250 层。
- 手感定位：风暴高频、暴击、连锁、较脆；山崩低频、重击、破甲、较硬。

### 存档与迁移

- 存档规划 v15：`doctrine`、`ownedSkillMask`、`skillEverMask`；旧 v14 强制选流派并补发 9 技能。
- `skills_15` 成就改跨世 `skillEverMask` 口径，否则单世最多 9 个永远做不完。
- README 技能 2.0 段（2026-10-26 新增）目前标「未实现」，落地时要整体替换现有 15 技能口径。

### 实现前待拍板（默认按推荐）

1. 流派是否本世锁定：推荐是（否则打 Boss 前换流派，build 失去承诺感；转生后可重选给重玩理由）。
2. 旧档是否直接送 9 技能：推荐是（只让 build 重新选，保留成就/装备）。
3. `skills_15` 是否改跨世：推荐是。
4. 技能命名（偏中式玄幻）是否接受：可在实现前统一改名，不影响数值与 id。
5. v2.0 是否保留 B9 的重抽/禁选：推荐不做，留给 v2.1 的 21 张 flex 池（专属封闭池 P70 必集齐，没有抽不到核心的问题）。

### 风险与缓解（§14.1）

- 暴击率夹取致静电共鸣空转：新增 `RawCritChance`，溢出用原始值；单测 107% → +24% 暴伤。
- 防御转攻递归：只取装备防御，上限 25% 面板攻击，需单测。
- 技能伤害不吃暴击：风暴靠频率/连锁，文案明确「技能伤害不吃暴击」。
- 雷殛/余震递归：追加伤害不计数，每次事件最多一层。
- 无尽中位偏移：两套 build 各 50 种子，只认 235~250，不认纸面。
- UI 1280 宽：属性上移 20px、资源条 18px、技能栏仍在 592。
