## 1. 项目全景

### 1.1 架构

```
Bootstrap（场景里唯一的物体）
 └─ GameController   状态机：Fighting / WaitingRespawn / Shopping / SkillChoice / Reviving
     ├─ BattleSystem   伤害、暴击、技能触发、冷却、Buff
     ├─ LootSystem     掉落与词条随机
     ├─ EquipmentScore 装备评分（期望 DPS + 有效生命/8）
     ├─ StageCatalog   11 章 × 10 关，纯规则生成
     ├─ PlayerData     等级 / 巅峰 / 装备 / 技能槽 / 关卡进度
     ├─ SaveSystem     PlayerPrefs，3 个存档槽，v6 带迁移
     └─ GameUI         全部 UGUI 由代码搭（4 个 partial），无 prefab
```

### 1.2 核心循环

挂机打怪 → 掉落装备（30%）→ 自动换装（评分更高才换）→ 击杀给经验 → 升级/巅峰 → 推关。
每关击杀 3~6 只，最后一只必为精英，章末关底为 Boss。首通给金币。

### 1.3 关键公式（当前值）

| 项 | 公式 | 备注 |
|---|---|---|
| 升级经验 | `30 + 15L + 2L²` | Lv.1 需 47，Lv.99 需 21,117；1→100 共 733,920 |
| 怪物经验 | `(10+5L) × 类型(1/1.15/1.35) × 档次(1/2/5) × (1+0.07(L−1))` | Lv.110 Boss ≈ 24k~32k |
| 巅峰经验 | `2000 + 200p`，上限 P200 | 满级后每级递增；P0→200 累计 4,380,000 |
| 巅峰属性 | 每级 +1 攻 / +1 防 / +50 HP，每 10 级 +1 技能 | 技能共 15 张，槽位只有 6 个 |
| 伤害 | `攻击 × (1 − 防/(防+100+20×等级)) × 0.9~1.1`，暴击再乘倍率 | 百分比减伤，永不免疫 |
| 出手间隔 | `2 / (1 + 速度/20)`，下限 0.2s | 速度对间隔非线性 |
| 关卡怪级 | 第 c 章 `Lv.10(c−1)+1 … 10c` | 1-1 是 Lv.1，11-10 是 Lv.110 |
| Lv.110 额外倍率 | 生命/攻击/防御 ×3，速度 ×2（叠加精英 ×1.5 / Boss ×2.5） | `MaxTier*Factor` |

### 1.4 内容量

110 关、首通 480 只怪、15 张技能卡、5 种装备品质、7 种怪物词缀（Boss 不带词缀）、
3 个存档槽、首通金币合计 63,800。

## 4. 100 级之后到底在玩什么

### 4.1 经济

- 单只 Lv.110 怪经验：普通 4.8k~6.5k，精英 9.7k~13k，Boss 24k~32k。
- 单级巅峰需求：P0 2,000 → P100 22,000 → P199 41,800。
  **也就是说 1 只 Lv.110 Boss ≈ 1 级巅峰**（P100 时约 1.1 只，P0 时约 0.1 只）。
- 全程 P0→P200 累计 438 万经验。按第 11 章 5~6 只/关、~2 秒一只估算，
  折合约 **30~50 分钟游戏内时间**（x4 档约 8~12 分钟）；只打到 P150 约 25~35 分钟。

### 4.2 阵亡返经验把墙变成楼梯

`HandlePlayerDied` 按已打掉的血量占比给经验，且不扣金币、不掉进度（只清本关击杀数）。
11-10 第一次尝试通常能打掉 30~60% 血，等于每死一次拿 0.3~0.6 只 Boss 的经验。
新档探针就是这么过去的：**27 次尝试、26 次阵亡，把巅峰从 0 刷到 102，然后打通**。

所以终局的原型不是"变强了再挑战"，而是"反复送死，直到数值够"。
玩家没有任何决策：不能换装备（已是最好的）、不能改技能（槽已满）、只能等。

### 4.3 Lv.110 Boss 为什么是墙

按公式实算 Lv.110 远程 Boss：

- 攻击 ≈ 339 × 1.45（类型）× 2.5（档次）× 3（最高档）= **3,687**
- 速度 ≈ 43 × 1.45 × 1.5 × 2 = **187** → 出手间隔被压到下限 **0.2 秒（5 次/秒）**
- 对 Lv.100、防御 742 的主角：减伤 26% → **单次 ~2,700，DPS ~13,500**
- 主角 P0 满级传说约 7,275 血 → **0.5 秒阵亡**

而主角同档 DPS 约 3,000，需要 3 秒才能打掉 9,219 血的 Boss。
数值上必输，唯一翻盘手段是技能（免死、护盾、吸血、斩杀）与巅峰血量。
**这正是「巅峰 60 级后胜率靠技能而不是数值」的根源**。

## 5. 结构性判断

| # | 结论 | 证据 |
|---|---|---|
| 1 | **难度曲线是一条 100% 的直线 + 一堵墙** | 1~10 章稳态 100%，新档 109 关零阵亡；11-10 在 P0 是 0.5% |
| 2 | **装备能过精英、过不了 Boss** | 同一档 Lv.110 精英：稀有装备 0% → 传说装备 89.6~96.2%；Boss 无论装备都是 0.5% |

| 4 | **巅峰曲线太浅** | 每级 ≈ 1 只 Boss 经验，200 级全程 <1 小时；P150 后终局已无挑战 |

| 6 | **终局难度由掷骰决定** | 盗贼 Boss 44% vs 远程 91%（P100） |
| 7 | **金币不缺** | 首通 63,800 + 卖装备，强化一件传说 +15 共 54,000 |

## 6. 建议（按性价比排序）

1. **削平终局单点**：`MaxTierAttackFactor` 3 → 2.2、`MaxTierSpeedFactor` 2 → 1.5。
   让 Lv.110 Boss 的出手从 5 次/秒回到 3.5 次/秒，P0 的胜率从 0.5% 抬到 10~15%，
   同时保留「需要巅峰」的性质。
2. **巅峰经验改成超线性**：`ParagonExpToNext = 2000 + 200p + q·p²`。这里原本建议 `q=6`，实际落地先用 12、再用 20（见 8.3 的二次校准）。
   P0→200 累计从 438 万涨到约 1,700 万，终局从 40 分钟拉到 3~4 小时，
   让 P150 之后还有目标。
3. **阵亡返经验打个折**（例如 60%），并且对 Boss 只按 50% 折算；
   现在"送死"是收益最高的打法，这条会直接鼓励正确玩法。
4. **技能槽随巅峰扩展**：P60/P100/P150 各 +1 槽（6 → 9），
   否则第 7~15 张技能卡没有意义。
5. **终局 Boss 固定类型**（或按章节轮换），去掉 11-10 的掷骰；
   类型差异建议控制在 ±15% 以内。
6. **给 1~9 章加一点压力**：例如章末 Boss 也吃 `MaxTier*` 的一个较低档位（×1.3），
   或者把"越级挑战"做成可选高难，让挂机过程不是纯读条。

## 9. 装备洗练的经济账（2026-10-18）

洗练（`docs/equipment-reforge.md`）是第一个真正意义上的金币出口：重抽全部副词条、条数不变、主属性与强化等级不动，
费用 `(200 + 14×(Lv−1)) × 品质系数 × (1 + 0.6×已洗次数)`。

| 项 | 数值 |
|---|---|
| Lv.100 传说首次洗练 | 2,538 金币 |
| 第 2 / 3 次 | 4,060 / 5,583（每次 ×1.6 递增） |
| 一件洗到 20 次累计 | ≈ 34 万金币 |
| 满级时兜里 | ≈ 600 万金币 |
| 锁 0 / 1 / 2 / 3 条的单价倍率 | ×1 / ×3 / ×9 / ×27 |
| 锁 1 条洗一次（同装备第 4 次，实测） | 21,316 金币 |
| 锁 3 条洗一次（同装备第 5 次，实测） | 274,061 金币 |
| 锁 3 条追 80% 词条质量的中位累计 | ≈ 7 万金币（锁 0 条约 135 万；蒙特卡洛 10 万次，见设计文档 §10.6） |

两条设计约束决定了它只能当「软出口」：

1. **天花板不变**：抽样与掉落共用同一段 `RollAffixes(level, count)`，所以洗练的最好结果就是掉落的最好结果。它买的是确定性，不是强度上限——终局 BOSS 的 ×1.6 标定因此不用重调。
2. **边际收益递减**：词条集合固定、条数固定，洗 N 次后的期望质量收敛得很快；玩家会在「够了」的时候停手，那之后金币重新变成死钱。

同日上线的**锁词条**把「软出口」往前推了一格，但没动天花板：锁定只是把待抽条数从 4 压到 4−k，分布本身一字未改。锁 k 条后追到 80% 词条质量的中位次数 58 → 17 → 5.6 → 2.0，所以哪怕单价按 `3^k` 指数加价（锁 3 条一次 27 万），累计花费反而从约 135 万降到约 7 万——玩家买的是**确定性**，不是更强。这也正是「锁定」与「保底」的分界：保底改分布（会抬天花板，得重估终局 BOSS），锁定只改抽样自由度（天花板不变）。

如果以后要让金币继续有意义，方向是另开出口（成就 / 转生 / 提高强化上限），而不是再加锁定档位——锁定给的确定性是一次性的，锁完之后金币照样会堆起来。
洗练**不进探针**：`EndgamePacing` / `NewGameProgression` 的既有时间（108.0 / 113.7 min）仍是「一次都不洗」的玩家口径，不能拿来当作洗练加速的证据。
